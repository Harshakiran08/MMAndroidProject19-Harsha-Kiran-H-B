# Pashu-Aahar – Smart Cattle Nutrition Calculator

Pashu-Aahar is an Android application developed to assist dairy farmers in generating balanced and cost-effective cattle feed recommendations using locally available ingredients. The application focuses on improving dairy productivity, reducing dependency on expensive industrial cattle feed, and promoting scientific cattle nutrition practices through intelligent feed calculation systems.

---

# Project Overview

The application dynamically generates cattle feed recommendations based on:

* Cattle Breed
* Body Weight
* Age
* Milk Yield

The project was developed as part of an Android App Development internship under the Agriculture domain using modern Android development technologies and software engineering methodologies.

---

# Features Implemented

## Dynamic Feed Recommendation System

* Breed-specific feed calculations
* Supports Jersey, HF, and Desi cattle breeds
* Uses protein and energy ratio formulas

## Authentication System

* Secure Sign In and Create Account functionality
* Firebase Authentication integration

## Stepper-Based User Interface

* Multi-step cattle data entry workflow
* Farmer-friendly navigation system

## Cost Tracking and Analytics

* Feed expense comparison system
* Savings analysis using charts and graphs
* MPAndroidChart integration

## Veterinary Guidance Module

Educational tips regarding:

* Cattle hygiene
* Fodder storage
* Feeding practices
* Dairy management

## Multi-Language Support

* Language switching functionality
* Improved accessibility for regional users

## Offline Functionality

* Local database support using Room Database
* Offline-first application design
